# RPS Init Cards

Утилита для инициализации бесконтактных смарт-карт (Mifare) и загрузки их в базу данных Microsoft SQL Server через SSH-туннель.

## Возможности
- Интерактивный режим поточной записи карт (чтение UID, выдача ключа объекта на карту).
- Запись партий карт напрямую в базу данных MS SQL.
- Пакетная загрузка карт из текстового файла (CSV или список UID).
- Логирование всех прошитых карт в локальный файл.
- Подключение к БД через защищенный SSH-туннель (plink.exe).

## Зависимости
- pyscard
- pycryptodome
- pyinstaller (для сборки)
- Утилита plink.exe из пакета PuTTY.
